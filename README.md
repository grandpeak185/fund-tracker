# 境外基金投资组合监控系统

每日自动抓取三只境外基金净值、生成买卖信号、更新网页并推送到GitHub。

## 快速开始

### 第一步：创建GitHub仓库

1. 登录 [GitHub](https://github.com)，点击右上角 **+** → **New repository**
2. 仓库名称填 `fund-tracker`（或任意名称）
3. 选择 **Public**（公开，这样才能通过网页查看）
4. 勾选 **Add a README file**
5. 点击 **Create repository**

### 第二步：上传项目文件

将本目录下所有文件上传到仓库：

```
fund-tracker/
├── .github/
│   └── workflows/
│       └── daily-update.yml      # GitHub Actions 定时任务
├── src/
│   ├── main.py                   # 主运行脚本
│   ├── fetch_nav.py              # 净值抓取模块
│   ├── signal_engine.py          # 量化信号引擎
│   └── generate_report.py        # HTML报告生成器
├── data/                         # 运行时数据（自动生成）
├── config.json                   # 投资组合配置
├── requirements.txt
└── README.md
```

上传方式（任选其一）：

**方式A：通过网页上传**
1. 在仓库页面点击 **Add file** → **Upload files**
2. 拖入所有文件（注意保持目录结构）
3. 点击 **Commit changes**

**方式B：通过命令行**
```bash
git clone https://github.com/你的用户名/fund-tracker.git
cd fund-tracker
# 将所有文件复制到此处
git add -A
git commit -m "初始化基金追踪系统"
git push
```

### 第三步：开启GitHub Pages

1. 进入仓库 → **Settings** → **Pages**
2. Source 选择 **Deploy from a branch**
3. Branch 选择 **main**，文件夹选 **/(root)**
4. 点击 **Save**
5. 等待1-2分钟，页面顶部会显示你的网址：
   `https://你的用户名.github.io/fund-tracker/`

### 第四步：验证自动更新

1. 进入仓库 → **Actions** 标签页
2. 左侧应能看到 **"每日基金净值更新"** 工作流
3. 点击它，再点 **Run workflow** 手动触发一次测试
4. 等待运行完成（约1-2分钟），绿色 ✓ 表示成功
5. 刷新你的 Pages 网址，应能看到最新数据

### 自动更新时间

- **每天北京时间 12:00** 自动运行
- 运行流程：抓取净值 → 生成信号 → 更新HTML → 自动提交推送到GitHub
- 你只需访问 Pages 网址即可查看最新数据

## 量化信号规则

### 卖出信号

| 规则 | 名称 | 触发条件 |
|:---|:---|:---|
| S-01 | 止盈止损 | 累计收益 ≥+15% 止盈, ≥+25% 强止盈; ≤-8% 止损预警, ≤-12% 强止损 |
| S-02 | 趋势反转 | MA5 下穿 MA20（死叉） |
| S-04 | 仓位超配 | 当前权重超出目标 +3% |
| S-05 | 急跌熔断 | 5日跌幅 >15%，暂停自动操作 |

### 买入信号

| 规则 | 名称 | 触发条件 |
|:---|:---|:---|
| B-02 | 趋势确立 | MA5 上穿 MA20（金叉） |
| B-03 | 回撤企稳 | 从高点回撤15%-25%且3日波动<1% |
| B-04 | 现金过多 | 现金仓位 >30% |
| B-05 | 仓位低配 | 当前权重低于目标 -3% |

### 信号强度

- **强信号**（立即执行）：触及强止盈/止损线，或≥3条规则同时触发
- **中信号**（分批操作）：2条规则触发
- **弱信号**（观望预警）：1条规则触发

## 技术说明

- **净值数据源**：惠理官网 / JPMorgan AM / Fonds-Super-Markt / Morningstar
- **无需服务器**：纯静态HTML + GitHub Actions，零成本运行
- **无需API**：信号引擎使用Python内置量化规则，不依赖外部API
- **数据持久化**：净值历史和信号记录保存在 `data/` 目录，随仓库一起提交
